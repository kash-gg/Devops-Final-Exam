# Jira: clicks for the 1-mark task
1. Open the intended Scrum project > Backlog. Check existing tasks and active sprint first; avoid duplicates.
2. If a sprint is active, use it. Otherwise click Create sprint, add the relevant tickets, then Start sprint; enter dates and sprint goal, and confirm.
3. Open Board / Active sprints. Review each ticket's work; drag each COMPLETED ticket to Done.
4. Check that completed tickets are in the rightmost Done column. Leave incomplete work truthful.
5. Click Complete sprint. Review unfinished tickets, choose backlog/next sprint if needed, then confirm completion.
6. Open Reports > Burndown Chart (sometimes Burn-down chart) and select that sprint.
7. Open Sprint Report and review completed/incomplete tickets. Screenshot board, completed sprint, and report.

Say: A burn-down chart plots remaining work against time during a sprint.
The actual line compared with the ideal trend shows progress and scope changes.

If menus differ, use the project's Scrum backlog/report navigation. Do not create a
duplicate active sprint. User clicks only; Codex needs your screenshots or pasted
sprint/report details to verify. Jira remains BLOCKED until evidence is supplied.
